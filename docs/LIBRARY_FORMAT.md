# 素材库格式

绘话的「预设库」是一个纯本地的素材库：一个文件夹 + 一份 `presets.json` + 一个 `preview/` 图片目录。开源版不带任何内置素材，所有内容都由使用者自己导入；导入时只读本地文件，不上传、不联网。

## 1. 目录结构

```text
my-library/
  presets.json          必填
  preview/              必填，示例图
    poster-01.png
    poster-02.webp
  thumb/                可选，卡片缩略图；没有就用 preview 原图
    poster-01.png
```

- `preview/` 里的文件名必须和每条预设的 `image` 字段一致。
- 支持 `jpg/jpeg/png/webp/gif/avif/bmp`，单张 ≤ 40MB。
- 整库 ≤ 5000 条、≤ 6000 个文件、≤ 512MB（含图片）。
- 也可以直接把整个库压缩成 zip 后解压到任意位置，导入时选解压后的文件夹即可；如果选的文件夹里只有一层子目录（例如 `my-library/`），会自动往里找一层。

## 2. presets.json

最小可用示例见 [`examples/library-template/presets.json`](../examples/library-template/presets.json)。

```json
{
  "meta": {
    "source": "我的素材库",
    "license": "自制，允许商用",
    "scrapedAt": "2026-11-23",
    "count": 2
  },
  "categories": [
    { "id": "poster", "name": "海报", "nameEn": "Poster" }
  ],
  "presets": [
    {
      "id": "poster-01",
      "cat": "poster",
      "title": "雨夜霓虹海报",
      "prompt": "雨夜东京街头，霓虹灯牌倒映在湿地面，主体：{主体}",
      "params": { "主体": "一位撑伞的女孩" },
      "vars": "主体",
      "image": "poster-01.png"
    }
  ]
}
```

### 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `meta` | 否 | `source`、`license`、`scrapedAt`、`count` 都只用于展示；`count` 会被实际条数覆盖 |
| `categories` | 否 | `[{id,name,nameEn,icon,count}]`；缺省时按预设的 `cat` 自动生成分类 |
| `presets` | 是 | 至少 1 条，最多 5000 条 |

### 每条预设

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 库内唯一。收藏、最近使用、已装风格都靠它对应 |
| `cat` | 是 | 分类 id，对应 `categories[].id` |
| `title` | 是 | 卡片标题 |
| `prompt` | 是 | 中文提示词；用 `{变量}` 标出可替换的位置 |
| `promptEn` | 否 | 英文提示词；变量用同名英文，例如 `{subject}` |
| `params` | 否 | 变量默认值，例如 `{"主体":"一位撑伞的女孩"}` |
| `vars` / `varsEn` | 否 | 给人看的变量说明；真正的输入框以提示词里的 `{...}` 为准 |
| `image` | 否 | `preview/` 下的相对路径；找不到图不会导入失败，只显示占位 |
| `model` | 否 | 原模型说明（例如 `gpt-image-2`），只用于展示，不参与出图 |
| `desc` / `descEn` | 否 | 一句话描述 |
| `index` | 否 | 排序，越小越靠前 |

### 变量

- 变量写成 `{主体}`、`{风格}`；同一变量在提示词里出现多次会一起替换。
- 中文和英文各一套变量时，按出现顺序配对成输入框；中英数量不一致时多出来的一侧也能单独填。
- 缺省值放 `params`；用户清空输入框时，提示词里的占位符保持原样，并提示还差哪个变量。

### 比例

绘话会从示例图的真实宽高推断比例（1:1 / 4:3 / 3:4 / 16:9 / 9:16 / 3:2 / 2:3）。如果提示词里写死了比例（例如「竖版 9:16」），打开详情时会优先按提示词预选；修改比例会同步改写提示词里的那句比例说明，避免「选了 1:1、提示词写 4:3」的出图偏差。

### 需要参考图的预设

提示词里出现「附件 / 上传的图 / 参考图 / 这张图 / 原图 / 图中 / 图片中 / 照片中 / 把这张 / 输入图 / attached image / uploaded image / reference image / this image / input image」等词时，会标记为「需参考图」；此时「直接生成」会禁用，需要先在对话里带上参考图。

## 3. 导入、替换与移除

- 点「导入素材库」选文件夹后，绘话会把整个库复制到 `%APPDATA%\绘话\presets`，并重算分类计数、补齐缺省字段。
- 再导入一次会**整体替换**用户库；收藏和最近使用按预设 `id` 保留。
- 点「移除素材库」删除用户库；如果安装包自带内置库，会自动切回内置库，否则回到空状态。
- 导入失败会保留原有素材库，不会出现导入一半的状态。

## 4. 版权

素材库的提示词、示例图版权由导入者负责。开源版不附带任何第三方提示词或图片；`examples/library-template` 里的两张示例图是脚本生成的渐变图，可自由使用。
